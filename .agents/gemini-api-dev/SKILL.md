# Skill: gemini-api-dev

## Descripción

Este skill habilita el uso de la API de Gemini (Google AI) dentro del proyecto. Proporciona ejemplos y scripts para:
- Instalar el paquete `@google/genai` (JavaScript/TypeScript).
- Configurar la variable de entorno `GEMINI_API_KEY`.
- Ejecutar una llamada simple a `client.interactions.create`.

## Uso
1. Asegúrate de que el archivo `.env` contiene `GEMINI_API_KEY`.
2. Ejecuta `npm install @google/genai`.
3. Usa el script `src/geminiTest.ts` como ejemplo.

## Recursos
- Documentación oficial: https://aistudio.google.com/docs/get-started.md
- Código de ejemplo en `src/geminiTest.ts`.
